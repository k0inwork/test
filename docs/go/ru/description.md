# Архитектура Системы
(см. docs/go/ru/architecture.md)

Новая реализация PUM переходит от монолитной архитектуры Django к распределенным микросервисам на Go с использованием **Service Discovery**.

## Реестр Сервисов (Registry Service)
Центральный компонент, отвечающий за обнаружение сервисов. Каждому сервису при запуске необходимо зарегистрироваться.

# Конфигурация Системы (system.yaml)
(см. docs/go/ru/config.md)

Централизованный файл `system.yaml` определяет состав и поведение системы. Разделен на Core Services (Ядро), Optional Services (Дополнительные модули) и External Modules (Внешние интеграции).
