# Руководство по внешним интеграциям

Система полагается на несколько внешних сервисов для идентификации, мониторинга и управления инфраструктурой.

## 1. Аутентификация (LDAP и Kerberos)

### 1.1. LDAP
- **Реализация:** Использует `django-auth-ldap`.
- **Конфигурация:** В `settings.py` настроены два бэкенда LDAP (`LDAPBackend1`, `LDAPBackend2`) для избыточности.
- **Отображение групп:** Группы LDAP (например, `tsumadm`, `trafadm`) сопоставляются с разрешениями Django. Это позволяет осуществлять детальный контроль доступа на основе организационных ролей.
- **Поиск:** Настроен поиск пользователей в `ou=users,dc=strela` и групп в `ou=groups,dc=strela`.

### 1.2. Kerberos
- **Использование:** Упоминается в `variables.py` (`KERBEROS_USER`). Обычно используется для сквозной аутентификации (SSO) или безопасного взаимодействия между сервисами.

## 2. Мониторинг (Zabbix)

- **Интеграция:** Система взаимодействует с Zabbix для мониторинга состояния управляемых устройств.
- **Соглашение об именовании:** Продукты (PDU) генерируют свои имена в Zabbix, используя префикс, определенный в `GlobalSettings`.
- **Оповещение:** Система может отображать карты Zabbix на своем дашборде и реагировать на уровни серьезности проблем.

## 3. Управление инвентаризацией (GLPI)

- **Роль:** Источник истины для физической инфраструктуры.
- **Интеграция:** Синхронизируется через кастомную библиотеку (упомянутую в `requirements.txt`) и периодические задачи Celery.
- **Данные:** Синхронизирует названия дата-центров, положения в стойках и статус устройств.

## 4. Виртуализация (QEMU)

- **Использование:** Используется для размещения виртуальных шлюзов или сред тестирования.
- **Управление сетью:** Кастомные скрипты (`qemu-ifup-brcontrol`) управляют мостовыми интерфейсами для виртуальных машин QEMU, позволяя им участвовать в сети VXLAN, управляемой ARM.

## 5. Логирование (Graylog)

- **Роль:** Централизованный сбор логов.
- **Реализация:** Django настроен на отправку логов в Rotating File Handler, которые обычно подхватываются сборщиком логов и пересылаются в Graylog (как настроено в `GlobalSettings`).
